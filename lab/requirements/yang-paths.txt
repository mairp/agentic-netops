# Required YANG path qualification (FR-005) — SR Linux native models.
#
# Every path below is read over gNMI against the native srl_nokia-* models, which
# are the models the renderer writes and the executor verifies. There is no
# translation layer in the write path, so there is no gap between "the path the
# gate qualified" and "the path the product uses".
#
# Format: <label>|<gnmi get path>|<expectation>
#   content  — the path MUST come back with a non-empty value on a bootstrapped
#              node. An empty reply is a failure, not an absence.
#   optional — the subtree is legitimately empty until a Network renders onto it.
#              A well-formed reply (including NotFound) passes; an rpc error does
#              not. Content for these is covered by the construct suites.
#
# The default TARGETS are the two leaves, because the bootstrap tenants
# (vlan100 mac-vrf, VrfBlue ip-vrf, vxlan1) only exist there — the spines carry
# no tenant state by design and fabric_verify.sh asserts that separately.
srl_nokia-interfaces|/interface[name=ethernet-1/1]|content
srl_nokia-interfaces-subinterface|/interface[name=ethernet-1/1]/subinterface[index=0]|content
srl_nokia-interfaces-bridged|/interface[name=ethernet-1/3]/subinterface[index=0]|content
srl_nokia-system-info|/system/information|content
srl_nokia-system-gnmi-server|/system/gnmi-server|content
srl_nokia-system-aaa|/system/aaa/authentication|content

srl_nokia-bgp-vpn|/network-instance[name=vlan100]/protocols/bgp-vpn|content
