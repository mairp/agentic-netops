     1	# SONiC VM Conformance Overlay
     2	
     3	Profile: sonic-vm
     4	
     5	This overlay enables the full conformance profile for SONiC running with hardware emulation
     6	that requires KVM and nested virtualization support on the host.
     7	
     8	Requirements:
     9	- Nested virtualization enabled in the host BIOS and hypervisor
    10	- /dev/kvm available to containers (privileged Docker runtime)
    11	- CPU: >= 8 cores; Memory: >= 16 GB; Disk: >= 40 GB free
    12	- Docker runtime with `--device /dev/kvm` support
    13	
    14	Notes:
    15	- The sonic-vm image is pinned by digest in versions.lock.yaml and must be imported locally.
    16	- This profile may take significantly longer to boot than sonic-vs.
    17	- The bootstrap remains limited to TLS + gNMI enablement and persistence; the EVPN/SRv6 tests
    18	  program configuration via gNMI during qualification.
