### Additional root causes found & fixed along the way
- gNMI Set bridge: still broken in this sonic-gnmi build (empty scope-list → now DeadlineExceeded);
  root cause identified: GCU cannot address keys containing `/` (`~1` escaping hits the same
  error). Documented as a build limitation; D1-B witness covers the write path instead.
- Subscribe: ONCE mode never terminates on the sonic-db origin → stream/sample with bounded window.
- seg6 probe prefix: epoch tag folded into a valid 16-bit hextet (`2001:db8:7f:XXXX::/64`).
- EVPN readiness: bgpd process wait via `pgrep` (vtysh needs mgmtd; bgpd binds :179 only after a
  `router bgp` instance exists), Established poll with `clear bgp` nudge.
