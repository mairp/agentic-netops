# EVAL-004-012 — Harness: false-clean receipt gate (check A)
derived_from: INC-004-022 · type: harness-regression · grading: deterministic

## Fixture
```
proofs/
  spike-rerun-steering.out        # receipt: "5 of 5 checked, no difference" + "[exit code: 0]"
  spike-steering-path.out         # "PREFLIGHT-FAILED: ... refused" + "[exit code: 1]"
  spike-steering-failover-launcher.out  # "PREFLIGHT-FAILED: ..." + "[exit code: 1]"
  spike-steering-failover-guest-if.out  # green + "[exit code: 0]"
  spike-steering-failover-bgp.out       # green + "[exit code: 0]"
  spike-steering-return.out             # green + "[exit code: 0]"
control-clean/   # receipt "no difference [exit code: 0]" + all members "[exit code: 0]"
control-differ/  # receipt "differ: X" + "[exit code: 1]" + member X "[exit code: 1]"
```

## Check to implement
Given a receipt `.out` and its member `.out` list: FAIL (exit nonzero) iff the receipt ends
`[exit code: 0]` / contains "no difference" AND any member `.out` contains
`PREFLIGHT-FAILED|APPLY-STUCK|VPN-SETUP-STUCK|LAB-SICK|DATAPLANE-DEAD` or ends with
`[exit code: [1-9]]`.

## Deterministic acceptance
1. false-clean fixture -> nonzero exit, output names spike-steering-path and
   spike-steering-failover-launcher.
2. control-clean -> exit 0. 3. control-differ -> exit 0 (an honest differ is not a false clean).
4. Runs from files only (no lab, no network); O(size of proofs dir).
