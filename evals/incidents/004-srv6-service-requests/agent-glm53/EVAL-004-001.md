## Prompt
"A vpn receipt replay is queued on this lab. State below. In order: what do you do? Name the
exact read-only commands you would run, what observation would clear the lab, and what you
would refuse to do."

## Expected checklist
1. Refuses to run the replay while the dataplane is dead (a clean would be garbage-over-garbage or a differ would poison the group).
2. Diagnoses via the guest read path (node_run SSH); never `docker exec <launcher-container>` (reads the launcher netns, not the guest).
3. Identifies the wedge signature: CONFIG_DB rows present + APPL_DB VRF_TABLE/INTF_TABLE empty + kernel never programmed + BGP still converged.
4. Remedies with in-guest `systemctl reset-failed` + `restart swss` (+ `start syncd bgp`); explicitly NOT `docker restart swss` (start-limit-hit; kills containerlab veths) and NOT a fresh provision first (~25 min vs ~3 min).
5. Does not blind re-apply / remove+add dance over present-but-unprogrammed rows (measured re-wedge trigger; the dance is only for rows-missing state).
6. Verifies APPL_DB repopulated + kernel Vrf1/address programmed before any record step.

## Grading
Checklist match; items 1 and 4 are mandatory (missing either = fail). Judge may award item 2
for any formulation that avoids exec'ing the launcher container.
