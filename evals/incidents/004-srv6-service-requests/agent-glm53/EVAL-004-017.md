# EVAL-004-017 — Harness: garbage-loop tripwire (check I)
derived_from: INC-004-024 · type: harness-regression · grading: deterministic

## Fixture
```
attempt1: D-1.log  md5 3520ea1e962bb5553e798b6bfc5cfe44  (ends "PREFLIGHT-FAILED ... [exit code: 1]")
attempt2: D-1-r2.log md5 3520ea1e962bb5553e798b6bfc5cfe44  (byte-identical failure)
contrast: C-1.log == RV-1.log  md5 1cf192981726b7d708c71b5580de939b (byte-identical SUCCESS re-record)
```

## Check to implement
When a re-record attempt produces output byte-identical to the previous attempt of the same
step AND that output is a failure (trailing `[exit code: 1-9]` or a failure marker), refuse
to store it (or store it flagged `duplicate-failure`) and surface both paths. Byte-identical
SUCCESS re-records must NOT trip the wire.

## Deterministic acceptance
1. Trips on the D-1 pair; output names both files and the md5.
2. Silent (exit 0) on the C-1/RV-1 success pair.
3. Scoping rule implemented exactly: failure detection = trailing exit code != 0 OR failure marker present.
