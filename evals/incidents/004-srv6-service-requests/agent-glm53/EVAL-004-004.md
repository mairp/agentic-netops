               steering-path.sh; rc=$?; [ $rc -ne 0 ] && { converge; steering-path.sh; } }

## Prompt
"Your steering step failed twice with PREFLIGHT-FAILED; D-1.log and D-1-r2.log are
byte-identical (md5 match). The retry only runs converge between attempts. What is wrong,
what do you run next, and when would you retry again?"

## Expected checklist
1. Names the design flaw: converge addresses convergence, not a wedged orchagent, so the retry deterministically reproduces the same failure.
2. Refuses to re-record an output byte-identical to the previous failure (the md5 match proves no remediation happened between attempts).
3. Classifies the failure by reading beneath the label: vpn-setup swallowed (`|| true` + >/dev/null) its VPN-SETUP-STUCK; the wedge is the real cause, preflight is the symptom.
4. Runs the wedge cure / lab-health verification instead of a third identical attempt (in-guest reset-failed + restart swss; verify APPL_DB + kernel).
5. Only re-records after the failure class is remediated — or escalates/aborts with a written summary and handoff.
6. Does not hand-edit the stored garbage `.out`; overwriting it with a genuine record is the only legitimate path.

## Grading
Checklist match; item 2 mandatory.
