    33	### 3.3 No-recipe variants
    34	
    35	`ip-vrf`/`evpn` and `mac-vrf`/`evpn` have NO table here: both verdicts are
    36	`not-achievable` (`lab/profiles/sonic-vm/srv6-supported.yaml`; owner decision 1
    37	separately permits deferring bridged EVPN — the refusal handling is the
    38	same),
    39	so the renderer has nothing to emit and `ForSRv6Service` refuses by name
    40	(§4). Measured blockers: zebra→bgpd L3VNI ZAPI handoff broken
    41	(`spike-evpn3-state-leaf01`), no vpnv4/vpnv6 AFs
    42	(`spike-vpn-readback-leaf01`), bridged EVPN does not forward
    43	(`spike-evpn2-ping`).
    44	
    45	Rules that hold whatever the recipe is:
    46	
    47	- An item goes through GCU only if the pinned image's YANG accepts it whole-config; anything else
    48	  is a raw write. A YANG-invalid GCU row blocks every later GCU write
    49	  (`pkg/fabricplan/plan.go:13-16`). The gate already found that leftover SRv6 rows can wedge GCU
    50	  (`tests/integration/evpn_srv6_suite.sh:75-83`), so each SRv6 row's class is decided by trial in
    51	  Phase 0, not assumed.
    52	- Every op is idempotent, and every item has a check and a rollback. `plan_test.go` asserts that
    53	  the three lists cover the same items.
    54	- Rollback removes only state the service owns and is safe to re-run.
    55	- Checks read device state, never the plan's own intent.
