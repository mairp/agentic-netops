    26	Known exceptions:
    27	- The topology (`lab/topology.sonic-vm.clab.yml`) names the sonic-vm image by
    28	  TAG (`local/sonic-vm:202505`) instead of the one-form
    29	  `local/sonic-vm@sha256:<digest>` pin in versions.lock.yaml. Why: containerlab
    30	  cannot resolve a local image by digest without a registry — proof
    31	  `p1-image-by-digest` shows containerlab 0.79 normalizes `name@sha256:<digest>`
    32	  to a registry reference (`docker.io/local/...`) and pulls (and plain docker
    33	  behaves the same for an imported image, which carries no repository digest).
    34	  Guard: `scripts/provision.sh` asserts, before every sonic-vm bring-up, that
    35	  the tagged image's ID equals the pinned digest and fails the bring-up
    36	  otherwise (with a warning that this exception is in effect). Remediation
    37	  plan: serve the image from a local registry so the topology can name the
    38	  digest directly, then remove the exception and the warning.
